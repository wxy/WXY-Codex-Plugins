# 技术选题预研

把技术消息预研成可用于选题决策的简报：核对事实、找出真正的变化、形成观点、考虑最强反驳，再给出少量值得写的角度。

核心判断参考证据、新鲜度、实际关注、争议、读者影响、观点增量和传播表达。能量化就提供真实数字和口径，缺数据就标未知，不机械评分；热度不能抵消证据不足。

## 使用

调用 `$tech-topic-research`，例如：

> 帮我预研这条技术消息，读者是普通开发者。它真正改变了什么，值不值得写？给出依据、观点、最强反驳和一两个扎实角度。

也可以一次提供多条候选消息，要求先筛选再展开。默认中文，输出深度和格式可随任务调整，结论通常为“继续研究”“进入写作”或“暂时搁置”。

这是预研技能，不自动生成长文章，不发布内容，也不创建或修改定时任务。可在后续选题简报中复用。

## 安装

已有本市场时保留当前来源。首次安装可执行：

```sh
codex plugin marketplace list --json
# 仅当市场尚未注册时：
codex plugin marketplace add wxy/WXY-Codex-Plugins
codex plugin add tech-topic-research@wxy-codex-plugins
```

安装后在新 Codex 任务中使用。其他支持个人技能的云环境可按其技能安装流程导入 `skills/tech-topic-research/`，确认安装状态后使用；仅把文件放进工作目录不等于跨会话安装。

## 结构与边界

版本：0.1.0。技能仅包含 `SKILL.md` 和界面元数据 `agents/openai.yaml`，不带脚本、Hook、MCP 服务、账号凭证或自动化。

研究使用当前会话已具备的搜索、浏览或连接器能力；技能不会自行授予额外访问权限。无法查看的来源和无法核实的数字应明确说明，不能声称已经验证。
