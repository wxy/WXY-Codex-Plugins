# 硬核老王文风

独立的 Codex 写作技能，版本 0.1.0。和技术选题预研互补，不需要钩子、账号、平台接口或自动发布权限。

| 用法 | 例子 |
| --- | --- |
| 起草 | 用这些材料写一篇新闻，未知原因不推断。 |
| 润色 | 保留署名、引用和判断，只润色第二节。 |
| 审稿 | 只指出稿件哪里不像老王，附具体建议，别改原稿。 |
| 改编 | 把已确认的文章改成一条英文 X 主帖，保留适用条件。 |

文类：评论、采访、短点评、新闻叙事、技术介绍、个人回顾。操作决定能改到什么程度，体裁决定怎样组织材料。平台格式、保存和发布另由调用方处理。

Codex marketplace：`codex plugin add wxy-writing-style@wxy-codex-plugins`。安装后在新任务使用「硬核老王文风」，例如调用 `$wxy-writing-style`。源文件在 [SKILL.md](skills/wxy-writing-style/SKILL.md)；例文按需查阅。单独版本迭代，不需要导出全文语料。
