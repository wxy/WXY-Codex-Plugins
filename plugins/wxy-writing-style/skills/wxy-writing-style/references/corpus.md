# 例库取材与迭代

- 已有风格研究以 141 篇 Linux 中国归档的 WXY 作者署名记录为基线（包含联署，且非所有段落都是其文字）。新增署名和体裁例子仅采用已经具体核过归属的段落。候选目录不等于完整阅读，也不等于全部原创。
- [Linux 中国归档](https://huggingface.co/datasets/linux-cn/archive)以文章 ID 去重。WXY、硬核老王、王兴宇为用户确认的署名；另有 Linux 中国内的「老王」候选，归属有疑点时逐篇核查，不跨站默认。作者字段与译者、校对、引用、受访角色分开。
- 只用作者可归属的正文：文章下方评论及回复（包括作者自己的）不选、不计、不分析。栏目编译、被引材料、正文内他人留言、受访者回答和不明联署段落不进作者文风。公开包仅保留方法及必要公开链接，不收录私人稿件、聊天记录和全文语料。
- 一次性的当篇反馈当篇优先；明确长期适用或反复得到确认的改法，增加一条可执行规则和一个短例。旧文章用于参考，不强于用户现在的明确要求。更新版本时说明哪些规则改了、用在哪类场景，并对未放进例库的样稿回归。
